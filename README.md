# 💻 Student Management System (C Project with Colored UI)

## 📌 Description

This project is developed using the C programming language.
It is a **menu-driven Student Management System** with a **colored console interface and box-style UI design** for better user experience.

---

## 🎯 Features

* ➕ Add student (ID, Name, Marks)
* 📋 Display all students
* 🔍 Search student by ID
* 🎨 Colored output (better readability)
* 📦 Box-style UI layout
* 🧭 Simple menu-driven program

---

## 🛠️ Technologies Used

* C Programming Language
* GCC Compiler
* VS Code / CodeBlocks

---

## ▶️ How to Run the Program

### Step 1: Compile

gcc student.c -o student

### Step 2: Run (Linux / Mac)

./student

### Step 3: Run (Windows)

student.exe
